# Campus Internship Tracker

A responsive web-based platform designed to help students explore internship opportunities, discover hiring companies, build relevant skills, and access useful career resources.

## Features

- 🎓 **Internship Opportunities**
  - Explore internship roles from companies such as Google, Amazon, Microsoft, and Adobe.
  - View available roles and application options.

- 🏢 **Top Hiring Companies**
  - Browse companies offering internship opportunities.

- 💻 **Skills in Demand**
  - Explore important skills such as Python, DSA, Web Development, Cloud Computing, Machine Learning, and Communication.

- 📚 **Student Resources**
  - Resume building
  - Interview preparation
  - LinkedIn tips
  - GitHub portfolio guidance
  - Aptitude practice

- 📱 **Responsive Design**
  - Designed to work across desktop, tablet, and mobile screen sizes.

- 📞 **Contact Section**
  - Provides contact and social media information for students.

## Technologies Used

- HTML5
- CSS3
- Font Awesome
- Responsive Web Design
